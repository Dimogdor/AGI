## 2. Ce que la mission entraîne

**L'ouverture d'une partie d'escarmouche** : poser ferme et marché tout de suite, puis un puits ;
sortir les trois premières unités (Émeutier, Barricadier, Franc-tireur) ; prendre et garder des zones ;
garnir une tourelle de tireurs. La nuit ajoute une leçon simple : **avancer groupé, ne pas courir
seul au loin** (exactement l'erreur qui perd les débuts d'escarmouche).

Il n'y a **aucun lac** : les trois points d'eau d'escarmouche (`game.nodes`) sont remplacés par
les **deux bornes d'incendie** (A et B, même logique de prise que les points d'eau, dessin d'une
borne rouge avec un filet d'eau quand elle est à nous). Le troisième point d'eau est supprimé.

Décor (`DECOR_THEMES.nightcity`) : lampadaires (s'allument quand le quartier est rallumé),
voitures garées, conteneurs, une barricade de palettes, des câbles tombés.

## 4. Objectifs

- **Principal** : détruire le dépôt Halvard.
- **Facultatifs** (un tampon chacun sur la page du carnet) :
  1. *Toute la rue allumée* — tenir les trois transformateurs en même temps.
  2. *L'eau des pompiers* — tenir les deux bornes d'incendie en même temps.
  3. *Avant l'aube* — détruire le dépôt avant 14:00 de mission (temps de jeu : 14 minutes ; à l'écran « en moins de 14 minutes »).
- **Victoire** : le dépôt tombe.
- **Défaite** : la Fraternelle tombe (une seule vie).
- **Minuteries** : l'aube commence à **14:00** (le ciel pâlit) ; à **16:00** il fait jour et la
  règle de la nuit cesse. Pas de défaite au temps.

## 5. Règle spéciale : la nuit

- **On ne voit que ce qui est éclairé.** Sources de lumière : la base (rayon 330), chaque
  transformateur à nous (rayon 400, permanent), la lampe de chaque unité (rayon 104, héros 170),
  la fusée éclairante (rayon 470), le dépôt adverse (rayon 190), les explosions.
- **Les machines dans le noir sont invisibles** : elles ne sont dessinées (silhouette sombre et
  deux yeux bleus) et ne peuvent être visées par nos tireurs et tourelles que si elles sont
  éclairées. La mêlée frappe toujours ce qu'elle touche.
- **Nos tireurs hors d'une grande lumière** (base, transformateur, fusée) portent moins loin :
  portée × [0,85 / 0,80 / 0,72].
- **Les machines voient dans le noir** : aucune pénalité pour elles.
- **Bouton FUSÉE ÉCLAIRANTE** : allume une fusée au centre de l'écran ; rayon 470 pendant
  14 s ; recharge [30 / 40 / 50] s.
- **À l'aube** (14:00 → 16:00) : le rayon de toutes les lumières grandit progressivement jusqu'à
  couvrir la rue ; à 16:00 la règle est levée.

## 7. Briefing

- **recap** : Depuis le printemps, Omnicorp gère l'eau et le courant de Valmont. Ses compteurs
  coupent les foyers dont le « score de fiabilité » baisse. Hier, ils ont coupé l'hôpital.
- **where** : Valmont, rue des Tanneurs — une nuit d'octobre 2028, sous la pluie.
- **goal** : Détruire le dépôt Halvard, au bout de la rue : c'est lui qui pilote les compteurs.
- **goal2** : Facultatif : rallumer les trois transformateurs ensemble · tenir les deux bornes
  d'incendie · finir avant l'aube (en moins de 14 minutes).
- **rule** : Il fait nuit. On ne voit leurs machines que dans la lumière ; nos tireurs portent
  moins loin dans le noir (−20 %). Reprenez les transformateurs pour rallumer la rue. Ère I, une
  seule vie.
- **tips** :
  1. Ferme et marché d'abord : sans vivres ni métal, pas d'armée. Comme en escarmouche.
  2. Avancez groupés, de lampe en lampe. Une unité seule dans le noir est une unité perdue.
  3. Gardez la FUSÉE ÉCLAIRANTE pour voir arriver une attaque, pas pour regarder.

Comptes rendus (écran de fin) :
- **debrief** (victoire) : Le dépôt Halvard a brûlé jusqu'au matin. À l'aube, quelqu'un avait peint
  sur le rideau de fer : « ICI, ON A COUPÉ LE COURANT À CEUX QUI COUPAIENT L'EAU. » Le jeudi,
  l'eau est revenue aux robinets. Omnicorp a parlé d'un « incident logistique ». Dans les
  quartiers voisins, on a compris autre chose : ça se casse.
- **fail** (échec) : Germinal s'est dispersée dans la nuit. Les compteurs tournent toujours. Mais
  la rue a entendu le bruit qu'a fait le dépôt quand vous l'avez touché. Recommencez.

## 9. Storyboard des planches

**P1 · Le robinet** — *Cadre* : plan serré sur un évier de cuisine. *Éléments* : le robinet (un
seul trait : bec horizontal 60→160 à y 80, coude, descente jusqu'à y 128 ; manette en T au-dessus,

(boîtier 320-420 × 70-170, écran 334-406 × 86-116). *Lumière* : neutre, lavis gris léger.
*Mouvement* : trois dernières gouttes tombent du bec, puis plus rien ; le voyant rouge du compteur
clignote. *Texte* : sur l'écran « SCORE 41 » ; sous l'écran « OMNICORP · RÉGIE ».

**P2 · La rue s'éteint** — *Cadre* : plan large d'une rue de nuit. *Éléments* : six immeubles
(rectangles lavés 0,16, x 20 → 462, hauteurs 110-176) avec fenêtres ambre ; trottoir y = 230 ;

*Lumière* : bleu nuit 0,10. *Mouvement* : les fenêtres s'éteignent une à une de gauche à droite ;
la croix de l'hôpital s'éteint en dernier, puis se rallume faiblement. *Texte* : aucun.

**P3 · Le comité** — *Cadre* : plan moyen, une salle sous une ampoule nue. *Éléments* : une table

**P4 · La radio** — *Cadre* : plan moyen sur la table de Sol. *Éléments* : table (y 206) ; poste
